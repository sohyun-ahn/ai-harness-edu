# 몇 토큰일까? (Lab 6)

`bench.py` 를 돌리기 **전에** 카드마다 예상값을 적는다. 돌린 뒤 `python lab6_tokens/quiz.py` 가 정답을 계산해 준다.
가장 가깝게 맞힌 사람이 이긴다. 틀린 이유를 한 줄씩 말해 본다.

필요한 실행: `python lab6_tokens/bench.py --levers baseline,brief,haiku,opus,cache,subagent` (rtk 카드는 `--levers baseline,rtk`)

## 생각할 거리

- 1·3번: 한 단어 답에도 Claude Code 기본 시스템 프롬프트와 도구 설명이 따라 들어간다. 그래서 「질문 길이」보다 「하네스 크기」가 비용을 좌우한다.
- 6번: 캐시는 **앞부분이 글자 하나까지 같아야** 맞는다. 앞부분에 날짜·시각을 넣으면 깨진다.
- 5번: 모델 라우팅은 토큰을 줄이는 게 아니라 **토큰당 값**을 줄인다. 구독 요금제에서도 큰 모델일수록 사용 한도가 빨리 줄어든다.
- 7번: 서브에이전트는 메인 컨텍스트를 아끼지만 전체 토큰을 줄여 주지는 않는다.
