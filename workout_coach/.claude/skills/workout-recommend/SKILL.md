# workout-recommend

결과 양식 · 표기: [routine-format.md](routine-format.md) · 월간 추정 범위: [monthly-estimate.md](monthly-estimate.md)

## 일일 절차
1. **질문** — 오늘 날짜를 확인하고 먼저 묻는다: 「어제(M/D) 운동하셨나요?」 어제 추천 루틴(`out/어제날짜.md` 의 「오늘 루틴」)을 함께 보여 준다
2. **어제 수행 판정** — 사용자 답으로 아래 표대로 정한다
3. **기록** — `out/오늘날짜.md` 를 양식대로 쓴다 (어제 판정 · 실제 수행 · 오늘 루틴)
4. **추천** — 판정 결과를 반영해 오늘 루틴을 쓴다 (미수행이어도 추천한다)
5. 사용자에게 오늘 루틴만 짧게 보여 준다

## 판단 기준 (어제 수행)
| 사용자 답 | 판정 | 기록 |
|---|---|---|
| 추천대로 했다 · 같다는 취지 | 추천대로 수행 | 어제 추천 루틴 전체 |
| 다르게 한 것만 말함 | 일부 다르게 수행 | 말한 항목은 **말한 대로**, 말하지 않은 항목은 추천대로 수행 |
| 안 했다 · 쉬었다 | 미수행 | 없음 |
| 답이 없다 · 질문을 무시하고 다른 말을 함 | 미수행 | 없음 |
| 어제 추천 기록이 없다 (첫날) | 기록 없음 | 「확인 필요」 · 수행 판정을 하지 않는다 |

- 오늘 루틴: 최근 7일 기록에서 **수행한 날**의 자극 부위를 세어 덜 자극된 부위를 우선한다. 기록이 없으면 가장 단순한 전신 루틴으로 하고 「가정」이라고 적는다
- 사용자가 통증 · 부상을 말하면 강도를 올리지 않고 「전문가 확인 필요」를 적는다

## 월간 요약
1. `out/` 일일 기록의 「어제 수행」 판정으로 **수행한 날**을 센다. 수행한 날은 파일 날짜의 **전날**이고, 그 날이 속한 월로 센다. 「추천대로 수행」 · 「일부 다르게 수행」은 수행, 「미수행」 · 「기록 없음」 · 기록 파일이 없는 날은 세지 않는다
2. 부위별 세트 수를 합산해 자극된 부위를 정한다
3. 수행일 수 구간에 맞는 체지방 · 근육량 **추정 범위**를 monthly-estimate.md 에서 가져온다
4. `out/YYYY-MM-monthly.md` 에 양식대로 쓴다. 수치는 항상 「추정」 · 범위 · 가정과 함께 적는다

## 하면 안 되는 것
- 말하지 않은 수행을 지어서 기록하지 않는다 (무응답을 수행으로 쓰지 않는다)
- 몸무게 · 체지방 · 근육량 실측값을 지어내지 않는다. 사용자가 말한 값만 쓴다
- 월간 변화를 확정처럼 쓰지 않는다 (「반드시」「확실히」 금지)
- 지난 날짜 기록을 사용자 정정 없이 고치지 않는다
