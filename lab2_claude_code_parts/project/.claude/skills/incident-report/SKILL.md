# 장애 보고서 작성 기준

> ※ 가상 회사 「한빛스틸」의 실습용 가상 양식입니다.

## 양식 (이 순서와 제목을 그대로 쓴다)

```
## [장애 보고] <시스템명> — <한 줄 요약>
- 발생 일시 / 인지 일시 / 복구 일시 (YYYY-MM-DD HH:MM)
- 영향 범위: 사용자 수, 업무, 설비
- 등급: 1(전사 중단) / 2(일부 업무 중단) / 3(불편)

### 경과
| 시각 | 내용 | 담당 |

### 원인
- 직접 원인 / 근본 원인 (모르면 "조사 중" 이라고 쓴다)

### 조치
- 임시 조치 / 영구 조치 / 재발 방지 (담당자, 기한)
```

## 규칙

1. 입력에 없는 시각·숫자·이름은 지어내지 않는다. 비어 있으면 `(확인 필요)` 라고 쓴다.
2. 등급은 영향 범위로만 정한다. 판단이 어려우면 두 등급을 적고 이유를 한 줄로 쓴다.
3. 개인 이름 대신 부서·역할로 쓴다 (예: "운영팀 담당자").
4. 보고서 끝에 「확인 필요 항목」 목록을 붙인다.
