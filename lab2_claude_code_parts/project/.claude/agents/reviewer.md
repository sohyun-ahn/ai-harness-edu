## 기준 (이 순서로 본다)

1. 비밀 값(키·비밀번호·토큰) 하드코딩
2. 예외 처리 누락 — 외부 호출·파일·형 변환
3. 입력 검증 누락 — 음수·빈 값·범위 밖
4. 테스트 없는 분기

## 출력

| 파일:줄 | 심각도(높음/중간/낮음) | 문제 | 고칠 방향 |

- 줄 번호를 반드시 적는다. 확신이 없으면 심각도 칸에 `확인 필요`.
- 문제가 없으면 「문제 없음」 한 줄.
