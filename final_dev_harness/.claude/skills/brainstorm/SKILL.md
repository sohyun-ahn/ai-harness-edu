# brainstorm

0. 아이디어.md 를 먼저 읽는다. 채워진 항목(이름 · 사용자 · 입력 · 출력 · 현재 방식)은 다시 묻지 않는다
1. 한 번에 질문 하나씩, 최대 5개: 누가 쓰나 · 입력 · 출력 · 꼭 필요한 기능 · 하지 않을 것
2. 이미 답이 주어진 항목은 묻지 않는다. 「알아서」면 가장 단순한 선택을 하고 가정으로 적는다
3. 결과: docs/brief.md — 목적 한 줄 · 사용자 · 입력 예시 · 출력 예시 · 기능 (필수 / 나중) · 하지 않을 것 · 가정
