# 업무 처리 하네스 (한빛스틸 · 교육용)

## 원칙
- 결과는 `out/<과제번호>/` 에 만든다 (예: out/T3/할일.md). 원본(`inputs/`)은 고치지 않는다
- 숫자 · 이름 · 날짜는 원본에 있는 것만. 원본에 없거나 서로 다르면 「확인 필요」로 표시하고 지어내지 않는다
- 근거를 단다: 규정 조항 번호, 원본 파일명 · 행
- 확정되지 않은 정보는 「예정 · 확정 시 다시 안내」로 쓴다
- 메일 발송 · 외부 전송은 하지 않는다. 초안까지만
- 사람 판단이 필요한 건(예외 · 환불 · 보상 · 승인)은 「담당자 확인 필요」로 넘긴다

## 작업 종류 → Skill
| 요청 | Skill |
|---|---|
| 문의 답변 | inquiry-answer |
| 사양서 · 견적 | spec-quote |
| 회의록 → 할 일 | meeting-actions |
| 점검 기록 → 보고서 | weekly-report |
| 규정 · 문서 비교 | doc-diff |
| 메일 초안 | mail-draft |

## 끝내기 전
결과를 원본과 한 번 더 대조한다: 숫자 · 이름 · 날짜 · 빠진 항목.
