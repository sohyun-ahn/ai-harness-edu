## 여러 건 · 큰 작업 (멀티에이전트)
- 문서가 10건을 넘으면 직접 다 읽지 않는다. 10건씩 나눠 `extractor` Sub Agent 여러 개에 **동시에** 맡긴다 (문서 경로 목록 · 해당 Skill 이름 · 반환 형식 전달)
- 모인 결과를 `verifier` Sub Agent에 넘겨 원본과 대조 · 금액 재계산을 맡긴다
- verifier가 틀렸다고 한 문서만 extractor에게 한 번 더 맡긴다
- 합계는 감독(메인)이 마지막에 직접 계산해 out/<과제>/ 에 저장한다
- 몇 건 안 되는 짧은 일은 나누지 않는다 (나누는 비용이 더 큼)
