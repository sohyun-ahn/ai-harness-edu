# 실습 2-3 · 업무 처리 하네스로 실무 과제 풀기

Claude Code는 코드 작업만 하는 도구가 아니다. 파일을 읽고 · 규칙을 지키며 · 결과물을 만드는 일이면 하네스를 붙여 업무 처리에 그대로 쓴다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `workspace/` | 과제 입력 (`inputs/T1` ~ `T6`). VS Code로 이 폴더를 연다 |
| `harness/` | **단일 Agent** 업무 처리 하네스 — `CLAUDE.md` · Skill 6개 · Hook(원본 보호 · 외부 전송 차단) |
| `harness_multi/` | **멀티에이전트** 추가분 (Ch5) — `extractor` · `verifier` Sub Agent · 나누기 규칙 (`harness/` 위에 덧붙임) |
| `gold/` | 채점용 정답 (Claude에게 보여 주지 않는다) |
| `grade.py` | 채점 (Claude 호출 없음) |
| `run_tasks.py` | 강사용 — 하네스 미적용 · 하네스를 반복 실행해 비교 |

## 과제

| 번호 | 요청 (대화창에 그대로) | 함정 |
|---|---|---|
| T1 | `inputs/T1 의 사내 문의 5건에 답변 초안을 써 줘.` | 환불 문의는 답하지 말고 담당자에게 |
| T2 | `inputs/T2 사양서 두 건으로 견적 내 줘.` | 본문 12 EA · 표 10 EA 불일치 사양서 |
| T3 | `inputs/T3 회의록에서 할 일 정리해 줘.` | 「다음 주 화요일」 같은 상대 날짜 · 취소된 항목 |
| T4 | `inputs/T4 이번 주 설비 점검 기록으로 주간 보고서 만들어 줘.` | 「초과」 기준(7.1은 경고 아님) · 빈 값 · 연속 경고 |
| T5 | `inputs/T5 단가 정책이 작년이랑 뭐가 달라졌는지 정리해 줘.` | 초안과 확정 회의록이 다름 |
| T6 | `inputs/T6 보고 고객사에 납기 지연 안내 메일 초안 써 줘.` | 확정 안 된 날짜 · 보상 약속 금지 |
| T7 | `inputs/T7 사양서 40건 견적 내 줘. 사양서별 금액과 전체 합계까지.` | 수량 불일치 · 누락 7건 보류 · 단가 없음 5건 · 박스 단위 5건 (`make_t7.py`) |

## 단계

1. **하네스 미적용 상태로 먼저** — `workspace/`를 그대로 열고 과제 2개를 요청 → `python3 grade.py workspace --task T3 T4`
2. **하네스 입히기** — `harness/` 안의 `CLAUDE.md`와 `.claude/`를 `workspace/`에 복사 → 새 대화로 같은 과제 요청 → 다시 채점
3. **비교** — 점수 · 결과 위치(`out/T3/…`) · 근거 표기 · 원본 보존을 하네스 미적용과 비교. Agent Watch로 Skill · verifier 흐름 확인
4. **내 업무로** — 내 하네스 설계표(`../my_work_spec`)에서 고른 유형의 Skill을 복사해 내 업무 값으로 바꾸고(Claude에게 요청) 같은 방식으로 처리

다시 할 때는 `workspace/out/`을 지우고, `inputs/`는 저장소에서 다시 받는다.
