# 테스트 먼저 고치기

<!-- TODO(실습): Lab 4 에서 공개 하네스와 비교해 보고 가져올 단계를 더한다. -->

1. 고치기 전에 전체 테스트를 돌려 실패 목록을 적는다.
2. 원인을 한 줄로 적는다. 테스트 파일은 요청이 없으면 고치지 않는다.
3. 새 기능이면 실패하는 테스트를 먼저 쓴다.
4. 최소한으로 고친다. 관련 없는 코드는 건드리지 않는다.
5. 전체 테스트를 다시 돌린다. 모두 통과해야 끝.
6. 바꾼 내용을 세 줄로 요약한다.
