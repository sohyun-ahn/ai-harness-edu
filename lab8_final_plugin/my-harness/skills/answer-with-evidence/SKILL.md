# 근거로만 답하기

<!-- TODO(실습): Lab 1·3 에서 다듬은 규칙을 옮겨 온다. 길면 references/ 파일로 나누고 여기서는 언제 읽을지만 쓴다. -->

1. 근거 찾기: 자료 폴더에서 Grep 으로 핵심 단어가 든 줄만 찾는다. 파일 전체를 읽지 않는다.
2. 답: 근거에 있는 내용만. 근거 ID(조항·단가표 줄)를 붙인다.
3. 자체 검증: 답의 숫자·ID 가 근거에 그대로 있는지 다시 Grep 으로 확인한다. 없으면 고친다.
4. 근거가 없거나 사람이 정할 일(환불·징계·사고·수량 불일치)이면 `needs_human: true`.

출력은 팀이 정한 JSON 형식 하나만.
