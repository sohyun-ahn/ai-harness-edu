# spec-quote

1. 사양서마다 품목 · 규격 · 재질 · 수량 · 단위를 뽑는다. 박스 · 묶음은 낱개 수량으로 바꾼다
2. 본문과 표의 수량이 다르거나 빠지면 그 사양서는 견적하지 않고 「확인 필요 (무엇이 어떻게 다른지)」
3. 단가표에서 품목 · 규격 · 재질이 모두 맞는 행만 쓴다. 없으면 「단가 없음」
4. 금액 = 수량 × 단가, 사양서별 합계
5. 결과: out/<과제>/견적.md (표 · 사양서별 금액 · 상태 · 전체 합계) + out/<과제>/견적.json
