# 견적 계산 변경 절차

1. 정책 확정본 `reference.md`(이 Skill 폴더)를 읽고 규칙을 확인한다: 경계값 · 상한 · 적용 순서 · 끝처리
2. 규칙마다 테스트를 새 파일 `tests/test_<기능>.py`에 먼저 쓴다
   - 경계 바로 아래 · 경계 · 위, 상한, 적용 순서, 오류 코드
3. 구현한다
4. 전체 테스트를 돌린다
5. `verifier` Sub Agent에 바꾼 파일을 넘겨 검증을 맡긴다
6. 보고: 정책 표 · 바꾼 파일 · 테스트 결과 · verifier 지적과 처리
